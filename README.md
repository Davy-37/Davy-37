## Projet mis en avant

### [textutils-davy](https://github.com/Davy-37/library_textutils) : bibliothèque Python open source

Une bibliothèque de traitement de texte publiée sur [PyPI](https://pypi.org/project/textutils-davy/), gérée comme un projet open source, des issues jusqu'à la publication.

```bash
pip install textutils-davy
```

- Travail par issues et jalons, une branche et une pull request par issue, revue de code, branche principale protégée.
- Contrôles automatisés : pytest, Black, Ruff, pre-commit, intégration continue GitHub Actions de Python 3.10 à 3.13.
- Versionnement sémantique, changelog, publication automatique sur PyPI à chaque release GitHub.
- Contributions croisées par fork et pull request avec une autre étudiante.
